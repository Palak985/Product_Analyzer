✅ BACKEND ROUTES (app.py)
   └─ GET /peer_analyses
      ├─ Lists all analysts with shared analyses
      ├─ Aggregates statistics for each analyst
      ├─ Filters and organizes peer products
      └─ Accessible to all authenticated users
   
   └─ GET /analyst/<analyst_id>
      ├─ Displays detailed analyst profile
      ├─ Shows performance metrics
      ├─ Lists all their shared analyses
      ├─ Calculates expertise areas
      └─ Validates analyst role
   
   └─ POST /api/toggle_analysis_sharing/<product_id>
      ├─ Toggles is_shared status
      ├─ Validates ownership (owner or admin)
      ├─ Returns updated status
      └─ Provides user feedback
   
   └─ GET /api/analyst_stats/<analyst_id>
      ├─ Returns JSON statistics
      ├─ Used for dashboards/charts
      └─ Includes category breakdown

🎮 USER EXPERIENCE FLOWS
═════════════════════════════════════════════════════════════════════════════

ANALYST WORKFLOW:
   1. Create analysis (existing flow)
   2. View analysis report
   3. See "Share with Peers" button (bottom right sidebar)
   4. Toggle to control visibility
   5. Appears in peer analyst network when shared
   6. Can view own profile as seen by others

VIEWER/OTHER ANALYST WORKFLOW:
   1. Click "Peer Analysts" button on dashboard
   2. Browse network of all sharing analysts
   3. Search for specific analysts
   4. Click analyst card for profile
   5. View their statistics and expertise
   6. Click "View Full Analysis" to see detailed reports
   7. Compare methodologies and learn from peers
